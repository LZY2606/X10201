# 网格诊室（Mesh Clinic）

本地三维网格拓扑缺陷诊断与修复计划审阅系统。所有网格都在浏览器（同构 TypeScript 核心）处理，
SQLite 仅用于保存文档与修复分支，不依赖任何外部服务。

## 运行

```bash
npm install
npm test -- --run
npm run dev -- --host 127.0.0.1 --port 5261 --strictPort
```

打开 http://127.0.0.1:5261 ，页面标题与顶栏均为「网格诊室」。点击「载入演示 OBJ」
或「载入带属性 PLY」可立即体验，也可导入自己的 `.obj` / `.ply`。

## 工作流

1. **导入**：OBJ 与 PLY（ASCII / little-endian / big-endian binary）。保留原始顶点、
   面、法线、纹理坐标、组、自定义标量属性，以及每条记录的原始字节/文本表示；
   每个元素在导入时获得稳定身份（`v#12`、`f#3` 等）。
2. **诊断**：非流形边、重复面（含反向）、退化三角形、孤立壳、方向不一致、
   带边界孔洞、bow-tie 顶点、近邻焊接候选。每条诊断给出涉及元素、一环邻域、
   数值判定证据（邻接面数、面积、绕向、环长等）与代表位置。
3. **计划审阅**：每个缺陷生成多个确定性计划，列出新增/删除/合并的元素、
   面积变化、边界环、对 UV seam / 尖锐法线 / 组 / 自定义属性的影响。
   孔洞提供扇形（不同扇心）与耳切等多种合法三角化。
4. **冲突与锁定**：互斥计划给出最小冲突区域（面+顶点）；可锁定 UV seam、
   组、球形几何区域，违反锁定的计划不会被应用。
5. **分叉与原子应用**：从原版本分叉组合多个计划；应用时先克隆文档，
   冲突/锁定/任何操作失败都会整体回滚，绝不留下部分拓扑。
6. **WebGL 视图**：原网格、诊断配色、计划新增面预览；可只看受影响的一环邻域；
   可并排比较两个修复分支。
7. **导出**：未修改文档导出与原文件**逐字节一致**；修改后未改元素保持原始顺序与
   原始 token/字节表示，新增元素采用确定顺序。再次导入导出幂等，且已修缺陷不复发、
   不引入新缺陷类别（测试覆盖）。

## 代码结构

- `src/core/` 同构网格核心（浏览器/Node/测试共用）
  - `types.ts` 数据模型与稳定身份
  - `obj-parser.ts` / `obj-writer.ts`、`ply-parser.ts` / `ply-codec.ts` 导入导出
  - `topology.ts` 邻接/边环/壳/bow-tie 拓扑内核
  - `diagnostics.ts` 七类（+近邻）诊断
  - `triangulate.ts` 确定性多方案三角化
  - `planner.ts` 修复计划、冲突检测、锁定校验
  - `apply.ts` 原子应用（克隆→校验→应用→失败回滚）
  - `math3d.ts` 确定性数字格式与几何
- `src/web/` 前端：原生 WebGL2 渲染器 + 侧栏审阅 UI（无重型框架）
- `src/server/` Vite Connect API（`api.mjs`）与 `node:sqlite` 持久化（`db.mjs`）
- `src/test/` Vitest：导入导出、七类缺陷、孔洞多解、UV seam、带属性 PLY、
  冲突计划、原子应用、确定导出、SQLite、规模网格（纯数据，不依赖截图）
